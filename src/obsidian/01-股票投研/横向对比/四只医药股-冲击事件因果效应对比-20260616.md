## 冲击性质分类

### 第1类：业务基本面受损——恢复慢，幅度大

| | 恒瑞 | 
|---|------|
| **冲击** | 集采丢掉了核心仿制药品种 |
| **因果效应** | -48% |
| **恢复时间** | 2年后仍gap=-12.5%（未完全恢复） |
| **原因** | 仿制药收入断了，估值体系需要从"创新+仿制"重新定价为"纯创新" |

### 第2类：业务冲击 + 宏观叠加——短期痛，有修复逻辑

| | 华东（集采） | 华东（COVID） | 
|---|------------|--------------|
| **冲击** | 核心产品失标 | 宏观恐慌放大 |
| **因果效应** | -5~7% | -21pp |
| **恢复时间** | 有少女针反转 | COVID后快速回弹 |
| **原因** | 有其他产品线补位 | 有医美新故事跳过估值体系 |

### 第3类：股东层面冲击——不是业务问题，修复快

| | 复星 |
|---|------|
| **冲击** | 控股股东财务危机 |
| **因果效应** | -10% |
| **恢复时间** | 1年（gap从-25%缩到-4%） |
| **原因** | 市场判断：公司业务没坏，坏的是爸爸 |

### 第4类：独立叙事——需要换分析框架

| | 科伦 |
|---|------|
| **冲击** | 不是集采，是ADC BD |
| **SCM结论** | 不适用 |
| **替代框架** | BD里程碑兑现 + 科伦博泰独立估值 |

## 方法论总结

### SCM在医药股集采分析中的适用条件

**SCM能做好**：
- ✅ 处理单元在预处理期与donor共享共同趋势因子（恒瑞↔CXO，复星↔疫苗）
- ✅ 事件是单一、清晰的冲击（集采丢标、债务危机公告）
- ✅ 预处理窗口足够长（≥2年）

**SCM做不好**：
- ❌ 处理单元有独立叙事/走势与行业脱钩（科伦）
- ❌ 事件与宏观冲击太近无法分离（华东×COVID）
- ❌ 事件本身就是渐进式的/无明确公告日（省级集采、政策预期）

### 四种方法的工具箱

| 方法 | 适用场景 | 优点 | 缺点 | 
|------|---------|------|------|
| 合成控制法（SCM） | 单一冲击，有合适donor | 构建反事实直观 | 对独立叙事无效 |
| 事件研究（Market Model） | 任何股票，计算CAR | 稳健，适合快速检验 | 长期CAR漂移 |
| DID/合成DID | 多个处理/对照单元 | 面板数据更强 | 需要对照组 |
| 叙事分析/BD框架 | 独立叙事股（科伦） | 灵活 | 不量化 |
