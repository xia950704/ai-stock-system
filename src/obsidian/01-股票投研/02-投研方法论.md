# 二、标的筛选方法论：三层漏斗

## 2.1 第一层：赛道分类

将25只股票按商业模式归类：

| 赛道 | 股票 | 数量 | 核心特征 |
|------|------|------|----------|
| **自研创新药** | 恒瑞、荣昌、科伦、百利天恒、百济、信达、康方、君实、贝达 | 9 | BD驱动+管线估值，弹性大 |
| **CRO/CDMO** | 药明、康龙、泰格、凯莱英 | 4 | 订单可见度高，但地缘风险大 |
| **转型药企** | 华东、复星、石药 | 3 | 仿制药→创新药过渡期 |
| **License-in** | 康哲、康诺亚 | 2 | 低风险低弹性 |
| **疫苗** | 智飞、万泰、沃森 | 3 | 代理+自研，政策敏感 |
| **医美** | 爱美客、昊海 | 2 | 高毛利但监管收缩 |
| **中药/老字号** | 健民、梓橦宫 | 2 | 稳健但增长乏力 |

## 2.2 第二层：商业模式判断

**核心问题：这家公司怎么赚钱？**

| 模式 | 代表 | 估值逻辑 | 风险点 |
|------|------|----------|--------|
| 自研创新药+BD | 恒瑞、荣昌、科伦、百利 | 管线估值×成功率 | 临床失败、BD不及预期 |
| CRO/CDMO | 药明、康龙、泰格、凯莱英 | PE+订单可见度 | BIOSECURE法案 |
| License-in | 康哲、康诺亚 | PE（价值股逻辑） | 分成模式，弹性小 |
| 代理+自研（疫苗） | 智飞、万泰、沃森 | PE+代理续约 | 代理权丢失、集采 |
| 医美消费 | 爱美客、昊海 | PE+产品生命周期 | 监管收紧、竞争加剧 |
| 传统中药 | 健民、梓橦宫 | PE+股息率 | 增长天花板 |

## 2.3 第三层：可投资性筛选

**必须同时满足的3个条件：**

1. **商业模式清晰**：能在一句话内说清怎么赚钱
2. **有明确催化剂**：未来6-12个月有可跟踪的事件（获批、BD、临床数据）
3. **估值有安全边际**：PE低于历史中位数，或PB<2，或有现金/BD首付支撑

**筛选结果：**

| 优先级 | 股票 | 理由 |
|--------|------|------|
| P0（核心跟踪） | 恒瑞、药明、华东、科伦、荣昌 | 商业模式清晰+有催化剂+估值合理 |
| P1（锚定参考） | 康诺亚、康方、信达、百利天恒、百济 | 港股/科创板锚定，逻辑强但不可投 |
| P2（观察等待） | 康哲、石药、梓橦宫 | 低估但缺弹性，适合防守 |
| P3（需深度分析） | 健民、爱美客、复星、贝达、康龙、泰格、凯莱英、昊海、智飞、万泰、沃森、君实 | 信息不足，需补全6模块 |

# 三、深度分析框架：6模块标准

每只股票必须完成以下6个模块，缺一不可：

## 模块1：投资笔记（主页）

**必须包含：**
- 一句话逻辑（商业模式+核心产品+当前状态）
- 当前定位表（估值/趋势/位置/基本面/商业模式）
- 关键价格位（历史高/低/支撑/阻力，至少7个价位）
- 建仓信号清单（5-6个可量化的触发条件）
- 观望条件（当前为什么不买）

**检查标准：** 能否在30秒内说清"这家公司值不值得看"

## 模块2：业务管线

**必须包含：**
- 核心产品清单（名称+适应症+状态+收入贡献）
- 在研管线（临床阶段+预计时间节点）
- BD交易（金额+伙伴+里程碑）
- 收入结构（各业务占比+增速）

**检查标准：** 能否画出业务地图，知道钱从哪来

## 模块3：事件时间线

**必须包含：**
- 历史重大事件（上市/集采/BD/获批/暴跌）
- 未来催化剂日历（未来12个月可跟踪事件）
- 事件-股价对应关系（事件发生前后股价变化）

**检查标准：** 能否预测"下一个催化剂是什么，什么时候"

## 模块4：技术分析

**必须包含：**
- 均线系统（MA5/20/60/250排列状态）
- 支撑阻力位（至少5个关键价位）
- 量价关系（近期放量/缩量信号）
- 趋势判断（多头/空头/震荡）

**检查标准：** 能否判断"现在是买还是等"

## 模块5：估值追踪

**必须包含：**
- 当前PE/PB vs 历史分位数
- 合理估值区间（基于行业/增速/盈利）
- 估值驱动因素（什么会让估值变化）
- 估值风险（什么会让估值压缩）

**检查标准：** 能否回答"现在贵还是便宜"

## 模块6：研发管线

**必须包含：**
- 管线梯队（上市/临床III/II/I/临床前）
- 核心管线成功率评估
- 管线价值估算（rNPV或可比公司）
- 管线风险（失败概率/时间风险）

**检查标准：** 能否估算"管线值多少钱"

| 催化剂日历 | 有具体时间节点 | ⚠️ 16只缺失 |

# 六、方法论使用指南

## 6.1 新股票接入流程

```
1. 确认代码+交易所 → 2. 赛道分类 → 3. 商业模式判断
   ↓
4. 可投资性筛选（P0/P1/P2/P3） → 5. 6模块分析
   ↓
6. 质量校验 → 7. 写入Obsidian → 8. 更新股票索引
```

## 6.2 定期维护流程

```
每周：
- 更新股价+PE
- 检查催化剂日历（是否有事件发生）
- 更新趋势判断（均线排列变化）

每月：
- 更新估值分位数
- 检查基本面变化（财报/公告）
- 更新事件时间线

每季度：
- 重新评估商业模式（是否发生变化）
- 重新分类赛道
- 更新P0/P1/P2/P3优先级
```

## 6.3 决策框架

```
看到一只股票 →
1. 它怎么赚钱？（商业模式）
2. 未来6-12个月有什么催化剂？（事件面）
3. 现在贵还是便宜？（估值面）
4. 趋势如何？（技术面）
5. 有什么风险？（风险面）

→ 满足3个以上正面信号 → 纳入P0/P1跟踪
→ 信息不足 → P3，先补全6模块
→ 逻辑破坏 → 移出跟踪池
```
