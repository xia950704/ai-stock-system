# 华东医药：阿卡波糖集采失标两阶段分解

> **核心结论**：集采本身只跌了 **-5~7%**。**COVID才是真正的杀伤器——把伤害翻了4倍。** 2021-04少女针获批后完全逆转估值叙事，2年后gap收窄到接近归零。

---

## 为什么需要两阶段分解

2020年1月的两个事件极其接近，无法用单一SCM分离：

| 事件 | 日期 | 性质 |
|------|------|------|
| 阿卡波糖集采失标（第二批国家集采） | 2020-01-17 | 业务冲击 |
| 武汉封城/COVID爆发 | 2020-01-23（仅6天后） | 宏观冲击 |

COVID使华东医药在**已被集采打击的脆弱位置**上再遭重创。两阶段分解法：先测量集采在COVID前的纯效应，再追溯COVID叠加后的总效应。

---

## 两套模型交叉验证

### 模型1：CXO池（7只药明康德/泰格/智飞/沃森/贝达/凯莱英/健民）

| 指标 | R²=0.28 |
|------|---------|
| Top donor | 智飞24.3% + 凯莱英22.1% + 健民15.8% |
| **Phase 1: 集采纯效应**（1月22日，3交易日） | **-6.9%** |
| **Phase 2: COVID叠加**（→3月23日，40交易日） | **-17.2pp** |
| 总效应（集采+COVID谷底） | -24.1% |
| 修复后（2021-04-01 少女针） | -16.9% |

### 模型2：Value混合池（复星医药为主）

| 指标 | R²=0.28 |
|------|---------|
| Top donor | 复星医药100%（simplex投影后其他归零） |
| **Phase 1: 集采纯效应** | **-4.2%** |
| **Phase 2: COVID叠加** | **-25.7pp** |
| 总效应 | -29.9% |
| 修复后 | +17.1% |

### 取均值

| 阶段 | 均值 |
|------|------|
| **集采纯冲击** | **-5.6%** |
| **COVID叠加效应** | **-21.5pp** |
| 集采+COVID总效应 | -27.0% |
| 2021-04少女针后 | 修复到-17%~+17% |

## 时间线全貌

以2020-01-17（集采开标）= 100为基准：

```
2020-01-17  阿卡波糖集采失标    → 100（基准）
2020-01-20~22  集采消化期       → 96.3（gap约-5%）
2020-01-23  武汉封城            → 93.9
2020-02-03  春节后开盘暴跌      → 86.6（gap约-9%）
2020-03-23  COVID底             → 72.7（gap约-27%）
2020-06-30  疫情后修复          → 113.9（gap约-9~-24%）
2020-12-31  横盘期              → 119.6（gap约-40% ← 最惨）
2021-04-01  少女针获批          → 174.7（gap约-17%~+17% ← 完全反转）
```

## 峰值→谷底分析

| 指标 | 数值 |
|------|------|
| 峰值 | 2018-06-06 at 102.1（synth=106.8/100.5） |
| 谷底 | 2020-03-23 at 21.5（synth=95.8/103.8） |
| 实际下跌 | -78.9% |
| 合成反事实下跌（CXO池） | +18.6%（CXO疫情期间没怎么跌）|
| 合成反事实下跌（Value池） | -39.0%（复星也跌了）|

**注意**：峰值2018-06-06是整个分析窗口起点，不代表华东的合理"零集采"水平。华东2018年初实际股价约53元（事件记录），2018-2020实际横盘。

---

## 关键解释

1. **集采的"罪"没有想象的那么大**：阿卡波糖虽重要，但有百令胶囊+医美补位。3个交易日只跌5-7%，说明市场很快消化
2. **COVID把一切放大了**：在集采后6周内COVID让gap扩大了~21pp。华东在疫情中弹性较差，部分因为集采已伤及信心
3. **少女针才是真正的game changer**：2021-04获批后华东从"仿制药被集采"的故事跳转为"医美新贵"，估值体系重置
4. **2年后完全修复**：到2022-02 gap只剩+3.5%，说明华东的业务+估值都已恢复到集采前的水平
