# 复星医药：复星系债务危机的因果效应

> **核心结论**：复星系债务危机导致复星医药超额下跌约 **-10%**。这个数字远小于恒瑞的-48%，因为它本质是控股股东的财务危机，不是业务基本面受损。市场1年后判明——gap收窄到-4%。

---

## 分析设置

| 项目 | 内容 |
|------|------|
| **事件** | 2022-09-01 复星系债务危机爆发（复星国际大规模出售资产偿债） |
| **预处理期** | 2018-06-01 → 2022-08-31（1035个交易日） |
| **后处理期** | 2022-09-01 → 2026-05-26（897个交易日） |
| **Donor pool** | 药明康德 8.2% + 泰格医药 13.4% + 健民集团 15.8% + **智飞生物 24.3%** + **沃森生物 3.1%** + 贝达药业 13.1% + 凯莱英 22.1% |
| **拟合优度** | 日收益率R² = **0.34**（4只中第二高） |
| **合理解释** | Top donors为疫苗股（智飞+沃森），因复必泰使复星具有疫苗属性，与CXO+疫苗股保持高相关 |

---

## 关键时间节点

以2022-09-01（基准日=100）：

| 期间 | gap% | 含义 |
|------|------|------|
| 1个月（2022-10-10） | **-17.8%** | 市场最恐慌期 |
| 3个月（2022-12-07） | **-10.2%** | 初步消化 |
| 6个月（2023-03-14） | **-24.8%** | 二次探底（持续资产出售报道） |
| 1年（2023-09-14） | **-4.0%** | 基本修复 |

---

## 峰值→谷底分析

| 指标 | 数值 |
|------|------|
| 预处理期峰值 | 2021-08-04 at **201.1**（复必泰+核心资产双顶） |
| 后处理期谷底 | 2024-02-05 at **48.8** |
| 实际下跌 | **-75.8%** |
| 合成反事实下跌 | **-66.0%** |
| **债务危机因果效应** | **-9.7%** |

关键洞察：这-75.8%的跌幅中，66.0%是行业性的（CXO+疫苗同期大崩盘），只有9.7%是复星特有的债务危机冲击。

---

## 事件研究（稳健性）

市场模型预处理期R²=0.24，beta=0.49（低于恒瑞的0.48，说明复星的市场联动性中等）

---

## 为什么只有-10%？

和恒瑞的-48%形成鲜明对比：

| 维度 | 恒瑞集采 | 复星债务危机 |
|------|---------|-------------|
| 冲击性质 | **业务基本面受损** | **控股股东财务问题** |
| 影响机制 | 仿制药收入没了，估值体系重新定价 | 担心母公司被迫减持复星医药股票 |
| 修复速度 | 2年仍-12.5% | 1年就收窄到-4% |
| 市场判断 | 业务真的坏了 | 公司业务没坏，坏的是爸爸 |

**对监控池的启发**：复星的问题从来不是基本面，而是复星系这个股东结构的信用风险。这个无法用估值模型解决。
