# 恒瑞医药：集采冲击的因果效应估计

> **核心结论**：第五批集采导致恒瑞医药超额下跌约 **-48%**。从2020-12峰值到2022-04谷底，恒瑞实际跌75.9%，合成反事实（7只低集采敞口医药股加权组合）跌28.0%。这是4只分析股票中最干净、最可信的因果估计。

---

## 分析设置

| 项目 | 内容 |
|------|------|
| **事件** | 2021-06-01 第五批国家集采恒瑞多品种丢标（碘克沙醇等） |
| **预处理期** | 2018-06-01 → 2021-05-31（727个交易日） |
| **后处理期** | 2021-06-01 → 2024-12-31（872个交易日） |
| **Donor pool** | 药明康德 9.6% + 泰格医药 13.4% + 健民集团 5.9% + 智飞生物 9.3% + 贝达药业 11.4% + 凯莱英 13.6%（OLS权重，未经simplex投影） |
| **拟合优度** | 日收益率R² = **0.39**（4只中最高） |
| **稳健性检验** | 事件研究市场模型 R²=0.27，1年CAR=-39.4% |

> 注：Simplex投影（非负+求和为1）后R²大幅下降，因此采用OLS权重（允许部分负权重）。Donor选股逻辑：CXO服务+疫苗+创新药+OTC中药，业务模式不依赖仿制药集采品种。

## 事件研究（稳健性检验）

市场模型：R_恒瑞 = -0.0014 + 0.4846 * R_行业（预处理期估计）

- 30天CAR：-27.6%
- 60天CAR：-46.6%
- 126天CAR（6个月）：-32.6%
- 252天CAR（1年）：**-39.4%**
- 504天CAR（2年）：+48.1%（反转，可能因donor 2023-2024跑输）

SCM的-48%峰值→谷底效应与事件研究-39%的1年CAR基本一致，SCM略高。

---

## 解释与启发

1. **冲击烈度**：集采前11个月是跌得最惨的阶段，到2022-04达到最大偏离
2. **修复过程**：2023年起差距逐步收窄（-39.5%→-12.5%），反映孙飘扬回归+BD转型的市场认可
3. **924行情逆转**：2024-09后恒瑞实际指数超越合成反事实（+36.8%），恒瑞的反弹弹性>同业
4. **方法论局限**：恒瑞2019-2021的"核心资产溢价"（40→97）是CXO/疫苗股没有的。最终估计的-48%实质是 **"集采冲击 + 核心资产泡沫破裂"的联合效应**，不是纯政策冲击

### 对建仓策略的启发

监控池的建仓价47，距谷底27已反弹80%+。SCM显示合成反事实（无集采的恒瑞）在2024-12约43.6，而恒瑞实际52.5——实际上已经修复到超越"无集采"水平。924行情后的定价已经包含了超过修复的预期。
