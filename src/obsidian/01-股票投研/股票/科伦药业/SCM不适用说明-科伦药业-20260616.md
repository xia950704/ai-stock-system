# 科伦药业：为什么SCM做不了？

> **一句话**：科伦药业不适合合成控制法。它的股价历史是一个独立叙事——2018-2021"被遗忘的输液龙头"横盘，2022默沙东ADC后暴涨。这个轨迹和任何donor组合的走势都正交。

---

## 尝试过的模型

| Donor池 | 事件 | R² | 结果 |
|---------|------|----|------|
| CXO 7只 | 2021-06-01 第五批集采 | **0.15** | ❌ 无效，合成涨90%而科伦跌 |
| CXO+Value 13只 | 2021-06-01 集采 | **0.17** | ❌ 无效，同上 |
| CXO 7只 | 2022-01-04 默沙东ADC启动 | **0.005** | ❌ 完全无预测力 |

---

## 为什么做不了

科伦药业的股价历史是**三段式**的：

```
2018-2021     横盘（被市场遗忘的输液龙头）    → 股价~15-20
2022          默沙东3笔BD合计超百亿美元       → 股价~18→36（+100%）
2023-2024     科伦博泰港股上市                → 股价继续爬升
```

同期donor（CXO+疫苗）的走势：

```
2018-2021     暴涨（核心资产+创新药溢价）     → 涨80-150%
2022          暴跌（美联储加息+创新药估值压缩）→ 跌50-70%
2023-2024     分化
```

两条轨迹几乎**正交**——前段donor涨科伦不涨，后段donor跌科伦涨。SCM的非负simplex权重无法用上涨的组合拟合横盘，也无法用下跌的组合拟合上涨。

---

## 替代分析框架

SCM不行，但科伦的分析框架应该是不同的：

### 科伦的集采故事

科伦确实有集采暴露（抗生素品种+省级输液集采），但：
- 省级输液集采是慢性病，不是急症
- 科伦的输液是刚需，价格压不穿成本线
- **科伦真正的价值不在输液，在ADC**（科伦博泰）

### 替代框架：BD里程碑驱动估值

科伦的股价驱动因素排序：
1. **默沙东ADC的临床里程碑进度**（首当其冲）
2. **科伦博泰的独立估值**（港股上市后的市场定价）
3. 输液+抗生素的稳定现金流（托底价值）
4. 集采（边际噪音，不是主叙事）

### 建议的追踪指标

```
默沙东ADC里程碑 → SKB-264(TROP2 ADC)临床数据读出
                  → 监管审批进度
                  → BD里程碑付款公告
科伦博泰股价     → 港股09990.HK
输液业务         → 量价跟踪（省级集采影响）
```

## 同类"SCM不适用"的股票特征

从科伦的教训中可以总结哪些股票不适合SCM：

1. **走势与行业脱钩的独立叙事股**（科伦：ADC BD改变了整个公司）
2. **上市时间短**的次新股（君实、康方、百济：A股数据不够）
3. **事件驱动型/反转型**股票（科伦：从一个估值体系跳到另一个）
