# 锚价偏离判断规则表（阶段 1 固化）

来源：个人上下文卡 场景 1 + 腾讯 API 实测

## 规则定义

| 偏离范围 | 状态 | 说明 |
|---------|------|------|
| `< -5%` | 买入区间 | 当前价显著低于锚价，建议考虑建仓 |
| `-5% ~ 0%` | 偏低估 | 当前价低于锚价，属于买入候选 |
| `0% ~ +5%` | 合理 | 当前价接近锚价，处于合理区间 |
| `+5% ~ +10%` | 偏高 | 当前价高于锚价，需谨慎关注 |
| `> +10%` | 超买 | 当前价显著高于锚价，建议观望或止盈 |

## 512400 处理

512400 ETF 无锚价（anchor=null），状态为"无锚价"。此编号由用户拍板，后续若有ETF对应锚价再更新。

## 状态枚举值

- `买入区间`：deviation < -5
- `偏低估`：-5 <= deviation < 0
- `合理`：0 <= deviation <= 5
- `偏高`：5 < deviation <= 10
- `超买`：deviation > 10
- `无锚价`：anchor=null

## 依赖

腾讯 API qt.gtimg.cn 提供实时价与历史日线。
GF-DMA 健康度使用 DuckDB daily_kline 数据。
