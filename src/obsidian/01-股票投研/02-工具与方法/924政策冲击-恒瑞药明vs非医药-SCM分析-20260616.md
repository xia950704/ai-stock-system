# 924政策冲击：恒瑞/药明 vs 非医药板块

> **核心结论**：924政策牛市中医药弹性>大盘，但恒瑞和药明走出了完全不同的轨迹——恒瑞"大涨后快速回落"，药明"大涨后持续走强"。差异根源在业务基本面不同。

### 方法论说明

预处理期R²仅0.06（恒瑞）和0.12（药明）。个股与大盘指数的日收益率相关性本就低于个股与同业（恒瑞vsCXO池R²=0.39）。结果的方向性可信（药明>恒瑞>大盘），具体数值仅供参考。

## 恒瑞 vs 药明的根本差异

```
924冲击后两条完全不同的路径：

恒瑞（脉冲型）：
大涨28.5% → 1周内掉到-5.9% → 持续弱于大盘 → 平均gap = -10.7%
↳ 924只是给了个"脉冲"，涨完了就跌回去了

药明（持续型）：
暴涨38.5% → 短暂回落到-3.2% → 重新走强 → 平均gap = +7.5%
↳ 924开启了趋势，涨完了继续涨
```

**原因分析**：

| 维度 | 恒瑞 | 药明康德 |
|------|------|---------|
| 924前处境 | 2021集采后转型中，核心资产旧伤未愈 | CXO处于周期底部，等待美联储降息催化 |
| 924后逻辑 | 政策好但基本面还是弱（创新药还在爬坡） | 政策好+基本面改善（美联储降息+CXO订单回暖） |
| 海外收入 | ~10% | ~50%+ |
| 投资者行为 | 924被当成"反弹出货"的机会 | 924被当成"拐点确认"的信号 |

**一句话**：恒瑞在924行情中被当作"反弹"卖了，药明被当作"拐点"买了。

## 对你监控池的启发

1. **恒瑞47的建仓价**——924行情后恒瑞跑输大盘-10.7%，说明市场对恒瑞的定价已从"政策牛"回到"基本面"。8-1政策落地后的建仓逻辑不变，但924的"医药β"已经被用掉了。

2. **药明125的出价**——药明在924后跑赢大盘+7.5%，且gap持续扩大（到2025-02达+35.8%）。说明你的建仓判断是对的：药明是CXO周期底部反转的标的，政策冲击对它不是脉冲而是一次趋势确认。

3. **924的教训**：同样一个政策冲击，不同股票的反应天差地别。政策牛中不是所有医药股都值得追——要看这个政策能"修复"什么。924修复了市场情绪（全部医药都涨），但只有有基本面支撑的（药明的海外订单）才能把情绪修复变成趋势修复。
