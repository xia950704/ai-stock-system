## 二、核心发现与交叉引用

### A 股截面信号共识（跨   

| 因子 | 方向 | 共识度 |
|------|------|--------|
| 反转效应 | 近期跌得多→未来表现好 | 三篇独立研究一致证实 |
| 小盘股 | 小市值强于大市值 | 一致 |
| 低换手率 | 低换手优于高换手 | 一致 |
| 低波动率 | 低波优于高波 | 一致 |
| 成长因子 | 几乎无效 | 一致 |
| 财务质量因子 | 几乎无效/弱有效 | 一致 |
| 动量追涨 | 负向（A股追涨杀跌效果差） | 一致 |

### AI工具的价值定位（跨      

| 主题 | 共识 |
|------|------|
| AI≠交易决策 | 所有项目一致认为AI是研究助理，非决策者 |
| 数据质量>模型能力 | QFLAM、QF-Forge、AI Hedge Fund改造版都强调本地可靠数据基础 |
| 沙箱/约束是刚需 | QFLAM沙箱、QF-Forge DSL、Alpha360定位——给AI边界是核心设计原则 |
| 成本可极低 | QFLAM用DeepSeek API 588轮<1元，AI Hedge Fund推荐DeepSeek |
| 可解释性第一 | 所有智能体决策必须带完整推理链路 |
