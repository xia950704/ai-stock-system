# P3-2 每日研判引擎设计文档

> 生成时间：2026-10-20
> 引擎位置：src/engine/

---

## 一、模块边界

| 模块 | 文件 | 职责 | 输入 | 输出 |
|---|---|---|---|---|
| 配置验证 | src/scripts/validate_stock_config.py | 检查环境变量、路径、配置契约 | 环境变量、文件系统 | PASS/FAIL + 错误信息 |
| 数据加载 | engine/data_loader.py | 读取并校验锚价、排名、组合、实时价格 | ~/harness/ 数据文件 | 结构化数据 + 索引 |
| 交易日判断 | engine/trading_day.py | 交易日状态、数据新鲜度 | 系统时间、文件 mtime | TRADING_DAY / NON_TRADING_DAY / DATA_STALE |
| 大盘研判 | engine/market_judge.py | 基于本地池聚合统计判断市场环境 | 锚价池、排名池 | 偏多/偏空/中性/无法判断 + 情景 |
| 股票分析 | engine/stock_judge.py | 逐只股票六层分析 | 池状态、研究笔记、JEV 结果 | 完整分析结构 + 行动建议 |
| JEV 适配 | engine/jev_adapter.py | JEV 调用封装、错误分级、降级 | state + questions | ok/error_code + answers |
| 报告生成 | engine/report.py | 生成 Markdown 报告 | 运行结果 | 报告文本 |
| CLI 编排 | engine/daily_judge.py | 全流程编排 | 命令行参数 | 报告文件 + JSON |

---

## 二、数据流

配置验证 -> 数据加载 -> 交易日判断 + 新鲜度检查 -> 大盘研判 -> JEV 探查 -> 股票逐只分析 -> 行动建议 -> 报告生成

---

## 三、证据综合逻辑

### 3.1 证据关系判断

| 关系 | 条件 |
|---|---|
| 相互支持 | 有支持证据且无冲突/缺口 |
| 部分支持，存在数据缺口 | 有支持证据但有缺口 |
| 存在冲突 | 有冲突证据 |
| 证据不足 | 无支持证据 |

### 3.2 证据来源

| 层级 | 可用数据 | 不可用数据 |
|---|---|---|
| 行情 | 当前价、锚价、偏离、状态、PE、涨跌幅 | 无 |
| 资金面 | 价格信号、排名评分、技术信号 | 主力资金、北向资金、融资融券 |
| 研发面 | Obsidian 研究笔记（最后更新日期） | 最新研发进展（无外部数据源） |
| 订单面 | 无 | 订单、销量、收入、商业化兑现 |
| JEV | Mock 模式 | 真实 JEV（当前 BLOCKED） |

### 3.3 降级规则

| 情况 | 行为 |
|---|---|
| JEV 调用失败 | 标记为缺口，不参与判断，不解释为中性 |
| 订单面无数据 | 标记为缺口 |
| 研发面无笔记 | 标记为缺口 |
| 锚价失效 | 行动建议 = OBSERVE |
| 数据过期 | 输出 DATA_STALE，不产生确定结论 |
| 大盘无数据 | 输出「无法判断」 |

## 四、行动建议规则

| 条件 | 行动 | 说明 |
|---|---|---|
| 偏离 < -5% | CONSIDER_ENTRY | 低于锚价，买入区间 |
| -5% <= 偏离 < 0 | WAIT | 略低，等待回调 |
| 0 <= 偏离 <= 5% | HOLD | 接近锚价 |
| 5% < 偏离 <= 10% | HOLD | 偏高但未到减仓 |
| 偏离 > 10% | CONSIDER_REDUCE | 显著偏高 |
| 锚价失效 | OBSERVE | 需重新评估 |
| 无数据 | INSUFFICIENT_EVIDENCE | 无法判断 |

注意：以上阈值基于锚价偏离度，不构成投资建议。用户需自行确认锚价有效性和仓位规则。

## 五、报告格式

报告包含 5 个部分：A. 运行状态、B. 大盘研判、C. 股票分析、D. 重点跟踪事项、E. 审计与追溯。

---

## 六、当前限制

1. JEV 不可用：真实 JEV 调用被 BLOCKED（model_na / insufficient / forbidden）
2. 无外部指数数据：大盘判断仅基于本地池聚合统计
3. 无订单数据：订单面无法分析
4. 无主力资金数据：资金面仅使用价格信号
5. 节假日无法确认：交易日判断为保守估计
6. 研究笔记可能陈旧：最后更新日期可能距今较远
